# Domain documentation

This is a single-context repository.

- Read the root `CONTEXT.md` before changing lifecycle vocabulary, state derivation, issue contracts, resolution receipts, or GitHub projection behavior.
- Keep durable architecture decisions under `docs/adr/`.
- Add an ADR when a decision changes an ownership boundary, authoritative source, public contract, or irreversible migration.
- Keep useful primary-source research in canonical product documentation when it affects behavior.
- Prototypes live on throwaway branches and leave only a linked verdict in the relevant issue or ADR.
